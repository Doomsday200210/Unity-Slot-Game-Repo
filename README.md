# 🎰 Unity Slot Machine Game

A 2D slot machine game developed using **Unity 6** and **C#**.

The game features three animated reels, randomized symbols, winning combinations, payouts, sound effects, lever animation, and game controls such as Start, Pause, Resume, and Restart.

---

## 🎮 Game Overview

The player starts the game with a fixed number of coins.

Each spin costs coins and generates a random result for all three reels.

### Symbols

The slot machine contains four symbols:

- 🍒 Cherry
- 🔔 Bell
- 7️⃣ Seven
- BAR

### Winning Rules

- **3 matching symbols** → Jackpot
- **2 matching symbols** → Small Win
- **No matching symbols** → Try Again

Different symbols have different jackpot payouts.

## 🕹️ Controls

| Button | Function |
|--------|----------|
| Start | Start the game |
| Spin | Spin all three reels |
| Pause | Pause the game |
| Resume | Continue the game |
| Restart | Restart the game |
